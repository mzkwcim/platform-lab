# Platform Lab

## Goal

Build a distributed platform consisting of:

- Cloudflare-managed DNS
- Linux servers hosted in OVH
- FastAPI application
- PostgreSQL database
- Raspberry Pi worker connected through a site-to-site tunnel
- Ansible-managed operating system configuration
- Kubernetes deployment

## Learning stages

1. Terraform and Cloudflare
2. Application and database
3. Site-to-site worker connectivity
4. Ansible automation
5. Kubernetes
6. CI/CD and monitoring
